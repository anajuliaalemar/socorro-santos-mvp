# Socorro Santos — Atendimento Especializado em Altas Habilidades / Superdotação

MVP desenvolvido para a disciplina de **Projeto de Software (Experiência Prática III)**. A solução consiste em um portal web educativo e sistema de triagem simplificado para direcionamento de famílias e educadores via WhatsApp.

## 🚀 Tecnologias Utilizadas
- **Linguagem:** Python 3.12
- **Framework Web:** Flask 3.0
- **ORM / Persistência:** SQLAlchemy (SQLite)
- **Front-end:** HTML5, CSS3, JavaScript e Bootstrap 5.3
- **Testes Automatizados:** Pytest

## 🎯 Alinhamento ao ODS 4
O projeto está conectado ao **ODS 4 (Educação de Qualidade)**, promovendo a democratização de informações técnicas sobre neurodivergência e facilitando a identificação e o acompanhamento pedagógico de estudantes com Altas Habilidades/Superdotação.
